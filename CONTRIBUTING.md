# How To Contribute

## Installation

- `git clone <repository-url>`
- `cd ember-rrule-generator`
- `pnpm install`

## Linting

- `pnpm lint`
- `pnpm lint:fix`

## Building the addon

- `pnpm build`

## Running tests

- `pnpm test` – Runs the test suite on the current Ember version
- `pnpm start`, then visit `/tests/` – Runs the tests in the browser while you develop

## Running the demo application

- `pnpm start`
- Visit the URL printed by Vite (the demo lives in `demo-app/`).
